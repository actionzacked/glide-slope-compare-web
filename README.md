# glide-slope-compare-web

Compare aircraft glide performance as a live side-view profile, in the browser.

Work in progress.

## Development

Use the Node version in `.nvmrc`, then:

```sh
npm ci
npm run dev
```

Run `npm run build` before `npm run test:smoke`, which tests the built site. The full list of checks is in `.github/workflows/checks.yml`.
