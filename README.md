# glide-slope-compare-web

Compare aircraft glide performance as a live side-view profile, in the browser.

Work in progress.

## Development

Use the Node version in `.nvmrc`, then:

```sh
npm ci
npm run dev
```

CI runs `format:check`, `lint`, `typecheck`, `knip`, `test`, `build` and `test:smoke` (after `npx playwright install chromium`).
